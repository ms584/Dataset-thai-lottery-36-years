# ผลสลากกินแบ่งรัฐบาลย้อนหลัง 36 ปี

ไฟล์ CSV มีผลสลากกินแบ่งรัฐบาล **864 งวด** ตั้งแต่วันที่ **16 ตุลาคม 2533 ถึง 16 พฤศจิกายน 2569** เรียงจากงวดล่าสุดไปเก่าสุด หนึ่งแถวต่อหนึ่งงวด

## คอลัมน์ในไฟล์

| คอลัมน์ | ความหมาย |
| --- | --- |
| `วัน` | วันที่ของเดือนที่ออกรางวัล เช่น `16` |
| `เดือน` | ชื่อเดือนภาษาไทย เช่น `พฤศจิกายน` |
| `ปี พ.ศ.` | ปีพุทธศักราช เช่น `2569` |
| `วันที่ ค.ศ. (YYYY-MM-DD)` | วันที่ออกรางวัลในรูปแบบปี-เดือน-วัน เช่น `2026-11-16` |
| `วันในสัปดาห์` | วันจันทร์ถึงวันอาทิตย์ คำนวณจากวันที่ออกรางวัลของแต่ละงวด |
| `รางวัลที่ 1` | เลขรางวัลที่ 1 ตามต้นฉบับ บางงวดเก่าใช้เลข 7 หลัก |
| `2 ตัวบน` | เลข 2 หลักสุดท้ายของรางวัลที่ 1 |
| `3 ตัวบน` | เลข 3 หลักสุดท้ายของรางวัลที่ 1 |
| `2 ตัวล่าง` | เลขรางวัลเลขท้าย 2 ตัว เช่น `06` |
| `เลขหน้า 3 ตัว ชุดที่ 1` ถึง `ชุดที่ 2` | เลขรางวัลเลขหน้า 3 ตัว แยกชุดละหนึ่งคอลัมน์ |
| `เลขท้าย 3 ตัว ชุดที่ 1` ถึง `ชุดที่ 4` | เลขรางวัลเลขท้าย 3 ตัว แยกชุดละหนึ่งคอลัมน์ |

ช่องเลขรางวัลที่เว้นว่างหมายถึงงวดนั้นไม่มีเลขชุดดังกล่าวในตารางต้นฉบับ ตัวอย่างเช่น งวด 16 ตุลาคม 2533 มีเลขท้าย 3 ตัว 4 ชุดและเว้นช่องเลขหน้า 3 ตัวทั้งสองชุด

## เปิดใน Excel

ไฟล์ใช้เครื่องหมายจุลภาคคั่นคอลัมน์และเข้ารหัส UTF-8 พร้อม BOM ใน Excel ให้เลือก **ข้อมูล → จากข้อความ/CSV** แล้วตั้งคอลัมน์เลขรางวัลให้เป็นชนิด **ข้อความ** ก่อนโหลด เพื่อเก็บศูนย์นำหน้าในเลขอย่าง `06` และ `011781`
